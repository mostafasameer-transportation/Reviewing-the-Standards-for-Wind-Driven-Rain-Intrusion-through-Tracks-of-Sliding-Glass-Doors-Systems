# Reviewing-the-Standards-for-Wind-Driven-Rain-Intrusion-through-Tracks-of-Sliding-Glass-Doors-Systems
This final report provides an overview of the project activities. This includes forming an advisory committee and assessing the performance of SGDs according to standards such as ASTM E331, ASTM E547, AAMA/WDMA/WDMA/CSA101/I.S.2/A440, North American Fenestration Standard/Specification.
